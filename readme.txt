== Description ==

**Woo Zero Search Miner Pro** يحوّل بياناتك إلى عمل ذكي! على قاعدة Woo Zero Search Miner الأساسية، تضيف هذه النسخة الاحترافية:

### المزايا الجديدة في Pro

* **📧 تنبيهات بريدية فورية**: عند ظهور مصطلح بحث جديد بلا نتائج، يصلك بريد فوراً.
* **📊 تقرير يومي مجدول**: ملخص يومي تلقاه في بريدك كل صباح.
* **🏠 Dashboard Widget**: عنصر "Zero Search" على الصفحة الرئيسية لـ WordPress admin يعرض آخر 5 مصطلحات بلا نتائج.
* **💬 إشعارات Slack/Discord**: أرسل تنبيهات فورية لـ Slack أو Discord مباشرة.
* **🎨 شريط تنقل + Breadcrumbs**: تنقل سهل بين التبويبات بدون أزرار المتصفح.
* **🌙 Dark Mode**: وضع داكن لحماية عينيك.
* **🏷️ White-label**: أعد وضع العلامة التجارية باسمك.
* **🔌 API hooks**: متكامل مع WordPress hooks للتخصيص المتقدم.

### المتطلبات

* WordPress 5.6+
* PHP 7.4+
* WooCommerce 5.0+
* **Woo Zero Search Miner Basic** (يجب تفعيله أولاً)
* مفتاح ترخيص Pro صالح

== Installation ==

1. ثبّت وفعّل "Woo Zero Search Miner Basic" أولاً.
2. ارفع مجلد `woo-zero-search-miner-pro` إلى `wp-content/plugins/`.
3. فعّل الإضافة من قائمة الإضافات.
4. اذهب إلى: Zero Search → ⚡ ترخيص Pro.
5. أدخل مفتاح الترخيص (للتجربة: `WZSMPRO-TRIAL-DEVELOPMENT-KEY-2026`).
6. اضغط "تفعيل الآن" - جميع مزايا Pro ستصبح متاحة.

== Frequently Asked Questions ==

= هل يمكنني تجربة Pro قبل الشراء؟ =
نعم، استخدم المفتاح التجريبي: `WZSMPRO-TRIAL-DEVELOPMENT-KEY-2026` - يعمل محلياً للتجربة فقط، لا يدعم الاستخدام التجاري.

= كم موقعاً يدعم الترخيص؟ =
ترخيص واحد يغطّي 5 مواقع (Domain/IP مختلفة).

= كم تستغرق فترة التحديثات؟ =
سنة كاملة من التحديثات المجانية مع كل شراء.

= هل يلزم تفعيل Basic قبل Pro؟ =
نعم - Pro يحتاج إلى Basic مفعّل كقاعدة، ثم يضيف المزايا فوقها.
